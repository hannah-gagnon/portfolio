HANNAH GAGNON — PORTFOLIO SITE (v1)

PREVIEW LOCALLY
  Unzip, then double-click index.html. Every page and link works offline
  (fonts load from Google Fonts when you're online).

GO LIVE (GitHub + GoDaddy, no subscriptions)
  1. Open your portfolio repo on github.com.
  2. Delete the old site files, but KEEP the file named CNAME if there is one
     (that's what connects hannah-gagnon.com).
  3. Click "Add file" > "Upload files" and drag in everything from this folder:
     index.html, work.html, about.html, misc.html, projects/, css/, js/, assets/
  4. Commit. GitHub Pages updates within a minute or two.
